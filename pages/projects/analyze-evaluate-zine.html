Instructor desk

Changes here reach every open browser in a second or two. Students do not need to reload.

Spotlight

Point the class at one zine. Students see a bar telling them where the room is, with a button to jump there. Nobody gets moved without choosing to.

The groups
Questions for each zine

Every student answers these for every group's zine. One section per box, one question per line. Reword a question in place rather than deleting the line, since deleting a line renumbers the questions after it.

Questions for the whole set

The whole class answers these about all the zines together. Writing {n} puts in the number of groups, so "the set of {n}" reads "the set of six" when there are six groups. Clearing a box hides that board, and the others keep their numbers.

Read the notes

Every note under its question, in the order it arrived. Easier to read aloud than the boards.
